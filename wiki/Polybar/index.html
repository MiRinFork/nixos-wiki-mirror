Polybar is a fast and easy-to-use status bar.

Getting started

You can copy the example configation from /nix/store/-polybar-/share/doc/polybar/examples/config.ini to ~/.config/polybar/config.ini and launch with polybar -c ~/.config/polybar/config.ini example

This default configuration requires the icon font 'siji' which can be installed as documented on [Fonts]
