### Searching by article type

The NixOS Wiki's core articles are divided into <a href=":Category:Resource" class="wikilink" title="five type categories">five type categories</a>. Each category link will list all pages in that category:

1.  <a href=":Category:Pedias" class="wikilink" title="Pedias">Pedias</a>, for encyclopedic description
2.  <a href=":Category:Guide" class="wikilink" title="Guides">Guides</a>, for broad hands-on understanding and connections to other learning resources
3.  <a href=":Category:Tutorial" class="wikilink" title="Tutorials">Tutorials</a>, intended to teach a particular process or project
4.  <a href=":Category:Cookbook" class="wikilink" title="Cookbooks">Cookbooks</a>, collections of tips and tricks
5.  <a href=":Category:Reference" class="wikilink" title="Reference">Reference</a>, full manuals and technical coverage

Pages are also organized by the six most prominent components of the <a href="Nix_Ecosystem" class="wikilink" title="Nix Ecosystem">Nix Ecosystem</a> — NixOS, <a href="Nix_package_manager" class="wikilink" title=" Nix: the package manager"> Nix: the package manager</a>, <a href="Nix_Expression_Language" class="wikilink" title=" Nix: the language (Nix Expressions)"> Nix: the language (Nix Expressions)</a>, Nixpkgs, NixOps and Hydra.

### News

- [planet.nixos.org](http://planet.nixos.org/) - Aggregator for blogs related to nix/nixOS
- [NixOS Discourse](https://discourse.nixos.org/) - Official forum
- [nixpkgs.news](https://nixpkgs.news) - news feed for nixpkgs, Inactive since July 7 2024

### Interactive websites

- [NixOS Packages Search](https://search.nixos.org/packages) - full-text search through all packages of NixOS
- [NixOS Option Search](https://search.nixos.org/options) - full-text search through all options of NixOS
- [Home Manager Option Search](https://home-manager-options.extranix.com/) - full-text search through all options of home-manager
- <a href="Noogle" class="wikilink" title="Noogle">Noogle</a> - Nix API search engine that lets you search nix functions
- [A tour of nix](https://nixcloud.io/tour/?id=1) - interactive Nix tutorial
- [Nix Channel Status](https://status.nixos.org/) - when nixpkgs/nixos channels were updated last
- [Hydra](https://hydra.nixos.org/) - official Nixpkgs CI/CD
- [Nix Review Tools Reports](https://malob.github.io/nix-review-tools-reports/) - reports showing problematic dependencies for major Hydra jobsets

\- [mynixos](https://mynixos.com) - full-text search through packages in nixpkgs and all options of NixOS, home-manager, nix-darwin

### Tutorials

- [How to learn Nix](https://ianthehenry.com/posts/how-to-learn-nix/) - A set of over 40 posts from 2021, looking at — as the author describes — not just what Nix does, but what it ***does***. It is their notes from reading the manual, doing experiments, and trying to deeply understand Nix.
- [Tutorial Introduction to Nix](https://rgoswami.me/posts/ccon-tut-nix/) - An introduction focused on the use of shell environments, for Python and with links to R versions as well
- [Interactive Tour of Nix](https://nixcloud.io/tour) - An interactive tutorial of the Nix Expression Language by Joachim Schiele and Paul Seitz
- [Nix shell workshop](https://github.com/nixcloud/nix-shell-workshop)
- [Scrive workshop](https://scrive.github.io/nix-workshop/) - Nix language and packaging workshop
- [Wombat's Book of Nix](https://mhwombat.codeberg.page/nix-book) - A book on Nix language and flakes for newcomers
- [NixOS & Flakes Book - An unofficial book for beginners](https://nixos-and-flakes.thiscute.world/) - A beginner friendly tutorial about NixOS and Flakes. By Ryan Yin
- [NixOS in Production](https://leanpub.com/nixos-in-production) - A NixOS handbook for professional use. By Gabriella Gonzalez
- [nix-1p](https://code.tvl.fyi/about/nix/nix-1p) - A (more or less) one page introduction to Nix, the language.
- [Nixcademy Blog](https://nixcademy.com/posts/) - high quality Nix and NixOS guides and tutorials

#### Video tutorials

- <a href="Wil_T_Nix_Guides" class="wikilink" title="Wil T Nix Guides">Wil T Nix Guides</a> - A video series in 8 parts, covering the Nix ecosystem from foundations, providing orientation with all available resources, and showing hands on how to get NixOS installed and running (including managing all your configuration through git and using Flakes).
- [Nix Friday](https://www.youtube.com/playlist?list=PLuVXx3vBwgelE9hbg5lH4w-JFU7llOqtI) - a series of 24 video streams of 1-2 hours on learning Nix and meeting community members
- [The Nix Hour](https://www.youtube.com/playlist?list=PLyzwHTVJlRc8yjlx4VR4LU5A5O44og9in) - A weekly beginner-oriented improvised QA-style lecture on Nix
- [Vimjoyer's Nix Tutorials](https://www.youtube.com/playlist?list=PLko9chwSoP-15ZtZxu64k_CuTzXrFpxPE) - A regularly released tutorial series about configuring things with Nix.
- [NixOS Config Guides for Nerds and Other Cool People](https://www.youtube.com/playlist?list=PL_WcXIXdDWWpuypAEKzZF2b5PijTluxRG) - A tutorial series geared towards people that have some Linux command line experience.
- [Nixology](https://www.youtube.com/playlist?list=PLRGI9KQ3_HP_OFRG6R-p4iFgMSK1t5BHs) - A tutorial series by Burke Libbey, originally released internally at Shopify
- [Informal intro to the Nix language, derivations and nixpkgs](https://youtu.be/9DJtHIpdp0Y) - A thorough introduction to the Nix language
- [EmergentMind's Nix Tutorials](https://m.youtube.com/playlist?list=PLAWyx2BxU4OyERRTbzNAaRHK08DQ0DD_l) - A tutorial series for Nix configuration and secrets management
