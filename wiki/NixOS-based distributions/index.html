Linux distributions and their relation to NixOS

This table lists a non-exhaustive selection of Linux distributions based on NixOS, forked from NixOS, or derived from Nix or NixOS in any other way. Github repositories are linked for distributions that do not have homepages elsewhere.

Distribution Relation to NixOS Status Notes
Athena OS Based on Pre-release For pentesting. Currently available under both Arch and Nix/NixOS
GLF OS Based on Released Community distro for beginners and gaming oriented
Guix System Forked Released NixOS but Guile Scheme instead of Nix and GNU underpinnings. Forked via "Developer & code sharing, project merging".
Liminix Based on Work in progress (WIP) Nix-based OpenWRT-style embedded Linux system for configuring consumer wifi routers.
NASty Based on WIP but released ;) NAS operating system built on NixOS and bcachefs.
NixBSD Forked Released Unofficial NixOS fork with a FreeBSD kernel.
NixNG Based on Work in progress (WIP) Lightweight NixOS for containers with multiple non-systemd init systems and a "minimal by default" package set.
RedNixOS Based on Alpha For cybersecurity enthusiasts.
SnowflakeOS Based on Alpha For beginners. Not yet ready for daily use.
Spectrum Includes nixpkgs Work in progress (WIP)
