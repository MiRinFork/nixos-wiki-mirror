Installation

Getting the installer

SD card images (SBCs and similar platforms)

For riscv64 it is possible to download images from the community.

  • Hifive Unmatched
  • VisionFive 1
  • VisionFive 2
  • STAR64
  • Lichee Pi 4A

Build or download the image.

If the image has the extension .zst, it will need to be decompressed before writing to installation device. Use nix-shell -p zstd --run "unzstd .img.zst" to decompress the image.

Binary cache

Example configuration snippet which can be used to add a third-party binary cache with RISCV support

nix.settings = {
  substituters = [
    "https://cache.ztier.in" # only nixos-unstable
  ];
  trusted-public-keys = [
    "cache.ztier.link-1:3P5j2ZB9dNgFFFVkCQWT3mh0E+S3rIWtZvoql64UaXM="
  ];
  experimental-features = [
    "nix-command"
    "flakes"
  ];
};

Known third-party binary caches with RISCV support:

  • misuzu (only for nixos-unstable)
