Question: When I do an import {}, which channel or path gets imported.

Answer:

Use nix repl '' on shell and then enter path in the repl to know what nixpkgs is currently being used.

Nix tools use $NIX_PATH to decide which path to use in the import call. The first entry in that variable is typically /.nix-defexpr/channels. If a user has explicitly added a channel named nixpkgs, then that channel is used in the import call. Otherwise, the nixpkgs= named entry is used for the import call.

Some tools don't fully respect $NIX_PATH and instead search ~/.nix-defexpr so there might be some unexpected behavior.
